# Framer's Tricks (Framer Components)

## In English

A collection of reusable components, code examples, and design tricks for [Framer](https://www.framer.com/).  
Perfect for designers and developers who want to speed up their workflow, reuse logic, and explore new visual techniques.

### ✨ What's Inside

- 📦 Custom components with props for maximum flexibility
- 🎨 Ready-to-use design utilities and effects
- 🌍 Multilingual & localized examples
- 💡 Useful tricks for better interactivity and animation

### 🧠 Why

I created this repository to organize and share various Framer code tricks and components I often use or experiment with.  
Whether you’re building something fast for a prototype or polishing a real product—these snippets can save you time.

### 📁 Structure

Each file contains a self-contained component with adjustable properties via Framer controls.

### 🚀 Getting Started

1. Copy a `.tsx` file into your Framer project.
2. Use the component as you would in any Framer Canvas.
3. Tweak the property controls in the right-hand sidebar.
