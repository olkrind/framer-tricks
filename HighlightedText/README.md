# HighlightedText (Framer Component)

## In English

### What is this?

`HighlightedText` is a flexible text component for [Framer](https://framer.com) that highlights a specified word inside a string with custom styling. You can adjust the font, color, alignment, spacing, and padding separately for the regular and highlighted parts of the text.

### Features

- Custom word highlighting
- Separate font weight and color for regular and highlighted text
- Full typographic control (font size, family, line height, spacing)
- Padding on all sides
- Horizontal alignment (left, center, right)

### How to use

1. Add the `HighlightedText` component to your Framer project.
2. In the property panel:
   - `Text`: Enter the full sentence.
   - `Highlight`: Specify the word you want to highlight.
   - `Color T`: Color of the main text.
   - `Weight T`: Font weight of the main text.
   - `Color H`: Highlight color.
   - `Weight H`: Font weight for the highlighted word.
   - `Size`, `Font`, `Line`, `Letter`: Typography settings.
   - `Align`: Choose text alignment.
   - `Padding T`, `B`, `L`, `R`: Set paddings as needed.

## На Русском

### Что это?

`HighlightedText` — это настраиваемый текстовый компонент для [Framer](https://framer.com), позволяющий выделить указанное слово в строке с применением индивидуальных стилей. Вы можете независимо управлять цветом, жирностью, выравниванием, отступами и типографикой как для обычного текста, так и для выделенного слова.

### Возможности

- Настраиваемое выделение слова
- Отдельные стили (цвет, жирность) для обычного текста и выделения
- Полный контроль над типографикой (размер, шрифт, межстрочный интервал, межбуквенное расстояние)
- Внутренние отступы
- Горизонтальное выравнивание (влево, по центру, вправо)

### Как использовать

1. Добавьте компонент `HighlightedText` в проект Framer.
2. В панели свойств:
   - `Text`: Введите весь текст.
   - `Highlight`: Укажите слово, которое нужно выделить.
   - `Color T`: Цвет основного текста.
   - `Weight T`: Жирность основного текста.
   - `Color H`: Цвет выделенного слова.
   - `Weight H`: Жирность выделенного слова.
   - `Size`, `Font`, `Line`, `Letter`: Параметры типографики.
   - `Align`: Горизонтальное выравнивание текста.
   - `Padding T`, `B`, `L`, `R`: Настройка внутренних отступов.

---

### 📌 Notes / Примечания

- Highlight works based on **exact match** inside the string.
- For best layout results, set the component width to **"Fill"** in the layout panel.
- Highlighting is **case-insensitive**.
